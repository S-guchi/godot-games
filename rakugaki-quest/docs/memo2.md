````markdown
# 落書きクエスト MVP仕様

## 目的

「落書きクエスト」は、タップだけで遊べる短編ローグライトゲーム。

プレイヤーは固定キャラを操作し、次々に出てくる変な敵を倒して、どこまで進めるか挑戦する。
敵を倒すたびに図鑑が埋まり、プレイごとの記録が残る。

UGC、画像生成、恒久育成、アリーナ要素はMVPでは扱わない。

---

## コンセプト

### 一言でいうと

```text
変な敵をタップで倒して、図鑑と最高記録を伸ばす短編ローグライト
````

### 体験イメージ

```text
バトル開始
↓
変な敵が出る
↓
タップで攻撃
↓
敵を倒す
↓
次の敵が出る
↓
数体倒すごとに強化を選ぶ
↓
HPが0になったら終了
↓
最高記録・図鑑・発見数が残る
```

---

## MVPでやること

### 実装する

* タップバトル
* 固定プレイヤーキャラ
* 敵の連続出現
* 敵撃破
* 敵の反撃
* ラン中の一時強化
* ゲームオーバー
* 最高記録
* 図鑑登録
* バトルログ

### 実装しない

* UGC
* プレイヤーによる落書き作成
* AI画像生成
* キャラの恒久育成
* アリーナ
* PvP
* ガチャ
* スタミナ
* デイリーミッション
* 複雑な装備
* 複雑な属性相性

## ゲーム構成

### 画面

MVPでは以下の4画面にする。

```text
バトル
図鑑
記録
設定
```

### 画面ごとの役割

| 画面  | 内容                 |
| --- | ------------------ |
| バトル | メインプレイ画面。敵を倒して進行する |
| 図鑑  | 倒した敵の一覧を見る         |
| 記録  | 最高到達数、倒した敵数などを見る   |
| 設定  | 音量、リセットなど最低限の設定    |

---

## バトル仕様

### 基本ルール

* プレイヤーは固定キャラを使う
* 敵が1体ずつ出現する
* プレイヤーはTAPボタンで攻撃する
* 攻撃後、敵が生きていれば反撃する
* 敵を倒すと次の敵が出る
* プレイヤーHPが0になるとゲームオーバー
* 1プレイは3〜5分程度を想定する

---

## 操作

### メイン操作

```text
TAP
```

TAPするとプレイヤーが敵に攻撃する。

### 操作方針

* 連打制限はMVPでは入れない
* 必殺ゲージは入れない
* 技選択は入れない
* 基本は1ボタンだけで遊べるようにする

---

## 戦闘フロー

```text
バトル開始
↓
敵を生成
↓
プレイヤーがTAP
↓
敵にダメージ
↓
敵HPが0以下なら撃破
↓
撃破数を加算
↓
図鑑に登録
↓
一定数撃破していたら強化選択
↓
次の敵を生成
↓
敵が生きていれば反撃
↓
プレイヤーHPが0以下ならゲームオーバー
```

## プレイヤーキャラ

### MVPでは固定キャラ

プレイヤーキャラは1体のみ。

例：

```text
マイコップ
```

### 初期ステータス例

| 項目      |  値 |
| ------- | -: |
| HP      | 50 |
| 攻撃力     | 10 |
| 防御力     |  0 |
| クリティカル率 | 5% |

### 注意

MVPではキャラ選択や育成は入れない。
キャラを増やす場合も、最初は「追加プレイアブルキャラ」として扱い、育成システムとは分ける。

## 敵キャラ

### 方針

敵は「変なもの」「ゆるいもの」「身近なものがモンスター化したもの」にする。

例：

* コーラ
* 消しゴム
* 靴下
* 歯ブラシ
* 焦げたパン
* 自販機
* ねむい枕
* しなしなレタス
* ぬるいお茶
* からまったイヤホン

### 敵データ例

| 項目   | 内容             |
| ---- | -------------- |
| ID   | enemy_cola     |
| 名前   | コーラ            |
| HP   | 30             |
| 攻撃力  | 8              |
| 出現階層 | 1〜5            |
| レア度  | common         |
| 図鑑説明 | ぬるくなると急に弱気になる。 |
| 技名   | あわあわアタック       |

## 進行設計

### 到達数

1体倒すごとに到達数を加算する。

```text
1体目
2体目
3体目
...
```

記録画面では最高到達数を表示する。

### 難易度上昇

敵は進行するほど少しずつ強くなる。

例：

```text
敵HP = 基礎HP + 到達数 × 2
敵攻撃力 = 基礎攻撃力 + floor(到達数 / 3)
```

### 敵出現

MVPではランダム出現でよい。

ただし、到達数ごとに出現範囲を分ける。

| 到達数   | 出現敵   |
| ----- | ----- |
| 1〜5   | 弱い敵   |
| 6〜10  | 少し強い敵 |
| 11〜20 | 中盤敵   |
| 21〜   | 強い敵   |

---

## ラン中強化

### 概要

一定数の敵を倒すと、今回のプレイ中だけ有効な強化を選べる。

### 発生タイミング

```text
3体撃破ごと
```

例：

```text
3体目撃破後
6体目撃破後
9体目撃破後
...
```

### 選択形式

3つの候補から1つ選ぶ。

### 強化例

| 強化名     | 効果              |
| ------- | --------------- |
| ぺちっ強化   | 攻撃力 +3          |
| じょうぶになる | 最大HP +10、HP +10 |
| たまに本気   | クリティカル率 +10%    |
| ふんばる    | 受けるダメージ -2      |
| おやつ休憩   | 敵を倒すたびHP +3     |
| 二度ぺち    | 20%の確率で2回攻撃     |
| あわてない心  | 敵の攻撃力 -1        |
| 先制ぺち    | 敵出現時に先制ダメージ     |

### 注意

* 強化はゲームオーバーでリセットされる
* 永続育成にはしない
* 強化はシンプルで分かりやすくする
* 数値よりも名前の楽しさを重視する

---

## 図鑑

### 目的

倒した敵を記録し、収集感を出す。

### 登録条件

敵を初めて倒した時点で図鑑に登録する。

### 図鑑に表示する情報

| 項目    | 内容             |
| ----- | -------------- |
| 敵画像   | 敵の見た目          |
| 名前    | コーラ            |
| 説明文   | ぬるくなると急に弱気になる。 |
| 初回撃破日 | 任意             |
| 撃破回数  | 任意             |
| レア度   | 任意             |

### MVPで最低限必要なもの

* 敵画像
* 敵名
* 説明文
* 登録済み/未登録の状態

---

## 記録

### 記録する内容

| 項目     |         内容 |
| ------ | ---------: |
| 最高到達数  |     例: 18体 |
| 累計撃破数  |    例: 120体 |
| 図鑑登録数  | 例: 12 / 50 |
| 最大ダメージ |         任意 |
| プレイ回数  |         任意 |

### MVPで最低限必要なもの

* 最高到達数
* 累計撃破数
* 図鑑登録数

## バトルログ

### 方針

バトルログはゲームの個性を出す重要要素。
単なる数値表示ではなく、変な表現を混ぜる。

### 表示例

```text
マイコップの「ぺちっ！」
コーラが ちょっとへこんだ！ -8
コーラの「あわあわアタック」！
マイコップは ふにゃっとした… -6
```

### 敵撃破時

```text
コーラは しゅわしゅわ消えた。
図鑑に コーラ が登録された！
```

### ゲームオーバー時

```text
マイコップは ふにゃふにゃになった。
記録：12体
```

TAPボタンは主役にする。


## アート方針

### 落書きに拘りすぎない

UGCやAI画像生成はMVPでは扱わない。
画像は公式素材として用意する。

### 表現候補

* へたうまイラスト
* ゆるい手描き風
* シンプルなドット絵
* 変なアイコン風

### 重要なこと

完璧な絵よりも、以下を優先する。

* 変さ
* 覚えやすさ
* 図鑑で見たくなること
* 技名や説明文との相性

## MVPの最小実装順

### Step 1: バトルの成立

* 敵を1体表示
* TAPでダメージ
* 敵が反撃
* HPが0になったら終了

### Step 2: 敵の連続出現

* 敵撃破
* 次の敵出現
* 撃破数カウント
* 難易度上昇

### Step 3: 図鑑

* 初撃破で登録
* 図鑑画面に表示
* 未登録はシルエットまたは「？？？」表示

### Step 4: 記録

* 最高到達数
* 累計撃破数
* 図鑑登録数

### Step 5: ラン中強化

* 3体撃破ごとに強化選択
* 3択から1つ選ぶ
* 現在のランにだけ反映

### Step 6: 演出

* 攻撃時の軽い揺れ
* ダメージ数字
* 敵撃破演出
* ログの面白文言

## MVP成功判定

### 見たい指標

* 初回プレイで3体以上倒すか
* 1プレイ後にもう一度遊ぶか
* 図鑑画面を開くか
* 強化選択まで到達するか
* 最高記録更新を目指したくなるか

### 良い兆候

* 「次の敵を見たい」と思える
* 「もう1回だけ」が起きる
* 図鑑説明文を読みたくなる
* 強化選択で少し迷う
* スクショしたくなる敵がいる

---

## 収益化方針

MVPでは収益化を急がない。
まずはゲームループが成立しているか確認する。

### 将来的な候補

* 広告削除
* リワード広告で1回復活
* 追加敵パック
* 追加エリアパック
* 完全版買い切り

### 相性が弱いもの

* 月額課金
* 強キャラガチャ
* スタミナ制
* PvPランキング課金
* 恒久育成素材課金

---

```text
UGCはやらない
AI画像生成もやらない
恒久育成はやらない
アリーナもやらない

固定キャラで短編ローグライトにする
敵を倒して図鑑と記録を伸ばす
強化はラン中だけ
収益化は後回し
```
